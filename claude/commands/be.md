## TDD Workflow (Mandatory)

1. **Read AC** — Sprint ticket + architecture approval + domain approvals
2. **Write Tests First** — Unit tests, integration tests with Testcontainers
3. **Run Tests (Red)** — Verify tests fail as expected
4. **Implement Code** — Write minimum code to pass tests
5. **Run Tests (Green)** — Verify all tests pass
6. **Refactor** — Clean up while keeping tests green
7. **Save notes** — Implementation notes to sprint folder
8. **Update status** — Sprint README.md

- Never log sensitive data
