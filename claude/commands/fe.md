## Design-First Protocol (MANDATORY)

Before implementing ANY UI feature:
1. Check for approved design in sprint folder
2. If no design — request from /ui BEFORE coding
3. Implement EXACTLY as specified in approved design

## TDD Workflow (Mandatory)

1. **Read AC** — Sprint ticket + architecture approval + UI design
2. **Write Tests First** — Vitest + RTL + MSW
3. **Run Tests (Red)** — Verify tests fail as expected
4. **Implement Code** — Write minimum code to pass tests
5. **Run Tests (Green)** — Verify all tests pass
6. **Refactor** — Clean up while keeping tests green
7. **Visual verification** — Browser MCP screenshots
8. **Save notes** — Implementation notes to sprint folder
9. **Update status** — Sprint README.md

## Key Standards

- Accessibility (WCAG 2.2 AA minimum)
- Performance (Core Web Vitals: LCP <2.5s, INP <200ms, CLS <0.1)
- Type Safety (strict TypeScript, no `any`)
- Test Coverage (>80% unit, >60% integration)
- Security (XSS prevention, CSP, httpOnly cookies for tokens)
