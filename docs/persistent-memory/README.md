# Persistent-Memory Coding Assistant — Concept & Future Vision

> "An AI coding assistant that never forgets."

This is a **planned tool, not yet implemented.** It explores a terminal-based
coding assistant that wraps the Claude API with a persistent memory layer —
saving every exchange to a vector store in real time and retrieving relevant
context automatically, so the model stays a reliable long-term collaborator
instead of losing context on compaction.

Before building from scratch, the same outcome may be reachable by **adopting
an existing tool** (e.g. Onyx, Obsidian, mem0). See the market research for the
build-vs-adopt landscape.
