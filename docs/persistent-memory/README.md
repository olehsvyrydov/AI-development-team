# Persistent-Memory Coding Assistant — Concept & Future Vision

> "An AI coding assistant that never forgets."

This is a **future-vision concept, not an implemented product.** It explores a
terminal-based coding assistant that wraps the Claude API with a persistent
memory layer — saving every exchange to a vector store in real time and
retrieving relevant context automatically, so the model stays a reliable
long-term collaborator instead of losing context on compaction.

Whether this is ever built — and whether as an open-source or commercial
effort — is undecided. The same outcome may be reached by **adopting an
existing tool** (e.g. Onyx, Obsidian, mem0) rather than writing one from
scratch. See the market research for the build-vs-adopt landscape.
