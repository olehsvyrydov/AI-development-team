| D-K01 | **Storage = HYBRID.** Markdown files stay the canonical, human-editable, git-friendly store. SQLite is an **optional, derived, gitignored, rebuildable** full-text/metadata index — a search accelerator, **NOT** the source of truth. | Architecture / Product | Files canonical preserves the two things the product sells (human-editable + git-diffable notes, and a zero-dep hub). SQLite-as-truth would forfeit both for FTS we can get as a cache; the corpus is small enough that the file scan answers in milliseconds today. The index is keyed `path\|mtime\|size`, non-authoritative, and discarded+rebuilt on drift (per /arch ADR-1). | /po (+ /arch) | 2026-06-13 |
| D-K02 | **The SQLite index lives only in the optional `claude/memory` package** (node:sqlite). The hub stays **zero-dependency**; absent index ⇒ today's file-scan behaviour. | Architecture | The hub's zero-dep guarantee is a stated principle, not an accident. `claude/memory` already depends on node:sqlite and degrades to digest-only — the established home + degrade pattern (/arch ADR-1, R6). | /po (+ /arch) | 2026-06-13 |
| D-K03 | **Canon = a deferred SEAM, not a shipped feature.** Design the overlay seam now (it extends the existing `overlay.js`), but **ship NO "Connect Canon" control until Canon's adapter is real.** | Product / Architecture | A dead control that promises a capability the backend cannot honour is the anti-pattern to avoid. The page already designs the seam (the connected-sources strip + the existing `egressDisclosed`/residency/method grounding fields), so lighting Canon up later is a backend wiring change, not a UI rebuild (/arch ADR-4, /aura §7). | /po | 2026-06-13 |
| D-K04 | **The open-source local default is COMPLETE and zero-egress.** No Canon marketing, no banner, no disabled tease in the free tool. Local is the whole system; Canon is discovered only at the connect surface, only when configured. | Product / Strategy | Provenance-first honesty (/apex): local is complete on its own; semantic/cited retrieval, RBAC, audit, cost receipts are Canon's value, not a degraded-looking free tier. No bulk delete in this slice. | Product / Security | A note is a rule the AI team follows; deleting one changes team behaviour. | D-K07 | **CRUD extends the EXISTING single guarded writer** (`addKbNote` → `editKbNote` / `deleteKbNote`) — same realpath-containment + O_EXCL + CAS-on-rev + mutex. **No second write path.** | Architecture / Security | One chokepoint keeps the atomicity/containment/audit guarantees and avoids a bypass (/arch ADR-2). | /po (+ /arch, /secops) | 2026-06-13 |
| D-K08 | **Connect-an-external-codebase = a READ-ONLY source record.** Realpath-pinned root, read-only + per-file realpath-contained ingest, bounded (globs + size/count caps, binary/VCS/deps skipped), honest filename/keyword index method. Connected content is **never merged into the vault scope**. | Architecture / Security / Product | The highest-leverage new capability (/max), kept honest + contained: the external tree is never mutated, a symlink escaping the root is skipped (no exfiltration), and the index method is labelled truthfully — never claimed as semantic (/arch §3, ADR-3). | /po (+ /arch, /secops) | 2026-06-13 |
| D-K09 | **Provenance-first IA.** Each note row leads with where it came from / whether it can be recalled (by meaning or filename) / whether it left the machine — **before** the note text. | Product / Design | The honesty differentiator: the human sees the trust facts first (/apex). | /po (+ /ui) | 2026-06-13 |

## Classification + workflow

- **Preset:** `solo` (per `workflow.yaml`). **Tracks:** all four tickets classify as **full** — new storage decision/index, new CRUD edit+delete writers, the connect-codebase source model + FS ingest, and the Canon overlay egress provider are schema/boundary/external-trust changes (significant change-class).
- **Hard gates with reasoning:**
  - **ARCH_APPROVED (hard)** — new storage decision + optional index, new CRUD writers, the connect-codebase source model + FS ingest, the Canon overlay seam: schema/boundary changes (`new_dependency`/`schema_change`/`cross_boundary`).
  - **SECOPS_APPROVED (hard, safety override)** — delete containment + the FS-READ of an external root + path-traversal/symlink + the index-must-not-widen-scope + secrets env-only + Canon egress-when-wired + no-egress local default: multiple new write/read/trust surfaces (`file_upload`/`external_input`/`network` triggers; never downgraded).
  - **APPROVAL_GATE, CODE_REVIEWED, VERIFIED (hard)** — required by the full track.
  - **DESIGN_APPROVED (soft)** — fed by the `/aura` build spec (`aura-page.md`), produced in parallel, + the investigation.
