# Bumbl — Persistent Memory IDE for Claude

> "An AI coding assistant that never forgets."

Bumbl is a planned terminal-based coding assistant that wraps the Claude API with a persistent memory layer. Unlike Claude Code, which loses context on compaction, Bumbl saves every exchange to a vector database in real-time and retrieves relevant context automatically — making Claude a reliable long-term collaborator.
